Install

Ready in a few minutes.

Windows: download, unzip, double-click. Everything Linen needs is in the folder.

Download for Windows (zip)

Windows 10 or 11, 64-bit. Not code-signed yet: if Windows warns, choose More info, then Run anyway.

Linux: it builds from source with one command.

  • Rust 1.85+from rustup.rs
  • mpv with libmpvfor playback (VA-API for hardware decoding)
  • Python 3yt-dlp runs on it; Linen downloads and updates yt-dlp itself
  • Node.js or Denofor YouTube's player challenge
$ git clone https://github.com/BugzySleeps/Linen.git $ cd Linen $ tools/dev-install.sh # builds it and adds it to your app menu $ linen

Made and tested on Wayland. Or skip the install and try it from the folder with cargo run.
